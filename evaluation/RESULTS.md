## Сравнение baseline и Agentic RAG

`agent_runner.py` измеряет долю отказов на пяти вопросах без ответа, долю ответов
и точное покрытие `expected_facts` для вопросов с ответом, p50/p95 задержки и
среднее число вызовов LLM. Метрика покрытия точная по подстроке: перефразированный
факт может быть правильным, но не засчитаться.

Результаты намеренно не записаны: в среде разработки база данных недоступна
(`InterfaceError` при проверке подключения), поэтому сравнение не запускалось и
значения не подменялись оценками. После запуска PostgreSQL, индексации
`data/eval_docs/` для `eval@example.com` и настройки `GEMINI_API_KEY` выполните:

```bash
python -m evaluation.agent_runner
```

Команда сохранит измерения в `evaluation/reports/agent_vs_baseline.json`.
